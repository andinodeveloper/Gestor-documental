¿Arrancamos desde cero con Next.js + TypeScript + PostgreSQL + Prisma, o tienes otro stack preferido? Para la Base mejor sería SQL Server, ya que es el esquema de base de datos que tiene la empresa.
¿La autenticación inicial será local con usuario/email y contraseña, o necesitas SSO corporativo desde la primera versión? Dejémoslo de forma local con usuario/email y contraseña, podemos dejar la estructura para la posterior configuración de SSO corporativo solo que hay que tomar en cuneta una restricción, la cual es que no todos los usuarios lectores van a tener correo corporativo, entonces algunos se tendrán que registrar de por otros medios para poder acceder.
¿En V1 el almacenamiento de archivos puede ser local en disco con una capa abstraída para migrar después, o ya debe salir integrado con SharePoint / S3 / OneDrive / otro? El almacenamiento hagámoslo de manera local, preparando la infraestructura necesaria para poder adaptarlo ya sea a un entorno de servidor local, (como el que emularemos ahorita) o a un entorno de almacenamiento de los archivos en la nube.
¿Qué formatos deben soportarse en la primera versión para carga, visualización y extracción IA? Mi recomendación inicial: PDF y DOCX. Si me parece PDF y DOCX.
¿Para la V1 basta con comentarios/sugerencias por ronda de revisión, dejando la edición colaborativa tipo OnlyOffice/Google/M365 para una fase posterior? Si, para facilidad de codificación y tener un MVP dejemos solo preparado todo para la posterior edición colaborativa. Aunque en vez de usar herramientas de paga de edición, sería mejor usar libre Office Portable embebido en la aplicación.
¿La aprobación en sistema es suficiente, o necesitas firma electrónica/digital? Con la aprobación en sistema es suficiente.
¿Debemos incluir notificaciones por correo y alertas de vigencia/revisión periódica desde la primera versión? Dejemos preparada la infraestructura para ello.
¿Los documentos obsoletos podrán ser visibles para lectores autorizados, o solo para administradores/editores? Los documentos obsoletos podrán ser visualizados por administradores y editores y también por aquellos usuarios que sean autorizados por el administrador, pudiendo activar o inactivar dicha autorización de visualización.
¿El permiso de descarga aprobado debe vencer obligatoriamente, o puede ser permanente? Debe vencer, podemos tener que como máximo sean 24 horas el plazo durante el cual una persona autorizada puede descargar un documento. 
¿Cuál será el proveedor inicial de IA y embeddings? Si no tienes preferencia, puedo dejarlo preparado para OpenAI con adaptador desacoplado. De momento no tengo una preferencia, aunque esto lo podemos modificar posteriormente. Déjalo preparado para OpenAI, aunque sería mejor algo que se pueda utilizar con cualquier proveedor de IA.
¿Confirmas que el código correcto para “Esquemas Documentales” en V1 será ESD y no ESQ? Si, es ESD.
¿Necesitas importación masiva inicial de documentos existentes, o podemos arrancar con seeds y carga manual? Arranquemos con sedes y carga manual.
